# 1-3.POP-UP-FORMAT.sav

**Tower:** 1-3 Tower of Traps
**App version:** v0.7-455
**Base file:** `1-3.sav` (unmodified original, 18 saves)
**Record replaced:** `AUTOSAVE_EXIT` -> `POP-UP-FORMAT`
**Value shape:** {time, data} table (matches the record it replaced)
**All other records byte-identical:** True

## What it tests

Whether a Pop-Up Wall records its state change as the step OFF the tile.

Pair 1 steps off the Pop-Up Wall at floor 3 (4,11) onto Empty at (5,11). Pair 2 opens a Gem Gate at floor 2 (9,10), one floor below, so a successful load proves the loader continued past pair 1 rather than stopping early.

## Payload

State-changing transitions, `(floor, x, y)`, 1-based, origin top-left:

```
  1. (3, 4,11) -> (3, 5,11)
  2. (2, 8,10) -> (2, 9,10)
  current position: (2,9,10)
```

## Expected result

Load succeeds and the player ends on the Gem Gate tile. A failure means the exit-move encoding is wrong.

_not yet run_

## How to use

1. Back up the real `1-3.sav` from the game save directory.
2. Copy this file over it, keeping the game-legal name `1-3.sav`.
3. Load the `POP-UP-FORMAT` slot in game.
4. Record the outcome above and in `RESULTS.md`.
5. Restore the backup.
