# 1-3.POPUP-TO-KEY.sav

**Tower:** 1-3 Tower of Traps
**App version:** v0.7-455
**Base file:** `1-3.sav` (unmodified original, 18 saves)
**Record replaced:** `AUTOSAVE_EXIT` -> `POPUP-TO-KEY`
**Value shape:** {time, data} table (matches the record it replaced)
**All other records byte-identical:** True

## What it tests

A Pop-Up Wall exit that lands on a pickup: two tiles changed by one move.

Pair 1 steps off the first Pop-Up Wall. Pair 2 steps off the second Pop-Up Wall directly onto a Light Key, so a single move both converts the wall and consumes the key. Pair 3 kills the Slime above the key to prove the loader continued.

## Payload

State-changing transitions, `(floor, x, y)`, 1-based, origin top-left:

```
  1. (3, 4,11) -> (3, 5,11)
  2. (3, 6, 8) -> (3, 7, 8)
  3. (3, 7, 8) -> (3, 7, 7)
  current position: (3,7,7)
```

## Expected result

Load succeeds. This is the case that forces applyTransition to return a SET of changed cells, not one cell.

## How to use

1. Back up the real `1-3.sav` from the game save directory.
2. Copy this file over it, keeping the game-legal name `1-3.sav`.
3. Load the `POPUP-TO-KEY` slot in game.
4. Record the outcome above and in `RESULTS.md`.
5. Restore the backup.
